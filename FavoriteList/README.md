# Favorite Countries App

**Author:** Аскар Кулахметов
**Theme:** Страны мира (Информационный справочник)

## Description
This is an iOS application built with Swift and UIKit that displays a list of 20 different countries. 

The application consists of two main screens:
1. **Main Screen:** Utilizes a `UITableView` to display a list of countries. Each custom cell shows the country's flag, name, and continent.
2. **Detail Screen:** Built using Auto Layout and `UIStackView`. It dynamically displays a large image of the flag, the country's title, a generated 5-star rating system, and a detailed multi-line description that automatically scales to fit the screen.
